# 스케치 무대 (ai-class_sketrch)

아이들이 그린 그림·색칠한 도안·찍은 사진이 프로젝터 위 무대(제주 바다 · 옛 포구 마을 · 마법의 밤)에 들어가 움직이는 어린이 AI 수업 도구다.
미디어아트 전시장의 "그림이 벽에서 살아 움직이는" 형식을 교실로 가져왔다.

아이는 계정을 만들지 않는다. 자리 번호와 별명만 쓴다.
이전 강의(제주민속자연사박물관 「우리 집 추억! 박물관 추억!」)의 전시물을 도안과 태그로 이어받았다.

## 0. 주소와 암호

- 첫 화면: https://jejugrapher.github.io/ai-class_sketrch/ (암호 필요)
- 아이 화면: https://jejugrapher.github.io/ai-class_sketrch/kid/ (암호 없음, QR로 들어옴)
- 강사 화면: https://jejugrapher.github.io/ai-class_sketrch/teacher/ (암호 필요)
- 프로젝터: https://jejugrapher.github.io/ai-class_sketrch/stage/ (처음에 아이 화면 QR이 크게 뜬다. 강사 화면 [QR 숨기기]로 무대를 보인다)

암호는 `gate.js` 에 SHA-256 해시로만 들어 있다. 암호를 바꾸려면 새 암호의 해시를 `HASH` 에 넣는다.
한 번 맞히면 그 브라우저 탭이 열려 있는 동안 다시 묻지 않는다.
QR 이미지는 `assets/qr_kid.png` (아이 화면 주소). 주소가 바뀌면 다시 만든다.

## 1. 화면 세 개

| 화면 | 주소 | 누가 | 하는 일 |
|---|---|---|---|
| 아이 | `kid/` | 아이 (폰·태블릿) | 자리 번호+별명 → 도안 고르기 → 그리기/사진 → 설명 쓰기(태그 조합) → AI로 바꾸기 또는 그대로 → 무대로 보내기. 배경(장소) 만들기, 내 무대에서 미리 실행 |
| 강사 | `teacher/` | 강사 (노트북) | 허용 스위치 6개, 무대 공간 선택, 장면 버튼(친구·씨름·춤), 예시 넣기, 아이 배경 심사 → 프로젝터에 올리기, **올라온 그림 보기·삭제**, 무대 비우기, **수업 끝 전체 초기화** |
| 프로젝터 | `stage/` | 프로젝터 | 무대만 표시. 첫 터치로 소리·전체화면 |

첫 화면 `index.html` 에 세 링크가 있다.

**접근 암호** — 강사 화면만 암호를 넣어야 열린다(`gate.js`). 첫 화면과 아이 화면은 암호가 없다.
정적 페이지라 소스를 보면 해시가 보이므로 진짜 보안은 아니다. 아이들이 강사 화면을 열지 못하게 막는 용도다.
암호를 바꾸려면 `gate.js` 의 `HASH` 를 새 암호의 SHA-256 으로 바꾼다.

**QR** — 프로젝터 화면은 첫 터치 뒤 아이 화면 QR(`assets/qr_kid.png`)을 크게 보여 준다. 화면을 누르거나 `Q` 키, 강사 화면의 [QR 보이기 / 숨기기]로 끄고 켠다.
아이 화면 주소가 바뀌면 QR을 다시 만든다: `python3 -c "import segno; segno.make('새주소', error='m').save('assets/qr_kid.png', scale=12, border=2, dark='#0b3d91')"`

## 2. 수업 흐름

1. 강사가 프로젝터 화면을 띄우고 한 번 누른다 (소리 켜짐)
2. 강사 화면에서 **그리기 열기** → 아이들이 도안을 골라 그린다
3. 강사가 **AI로 바꾸기** 또는 **그대로 쓰기**를 열면 아이 화면에 완성 버튼이 나타난다
4. 아이가 **무대로 보내기** → 프로젝터에 "7번 번개상어" 꼬리표와 함께 등장
5. 강사가 **씨름 대회 · 춤 시간 · 친구 만들기**로 장면을 연다
6. 올라온 그림은 강사 화면 아래 **올라온 그림**에 모인다. 올리면 안 되는 그림은 [삭제] — 프로젝터와 아이 보관함에서 함께 지워진다
7. 수업 후반: 강사가 **배경 만들기**를 열면 아이가 직접 장소를 그리고 물·땅 선을 정한다 → **선생님께 보여주기** → 강사 화면에 카드가 뜨고, 누르면 프로젝터가 그 배경으로 바뀐다 → 다른 아이들도 그 배경에 그림을 넣는다
8. 그림을 보낸 아이 화면에는 **조종판(화살표)과 말하기**가 나온다. 화살표를 누르고 있으면 프로젝터의 내 그림이 그쪽으로 움직이고(손을 떼면 3초 뒤 다시 혼자 다님), 말을 보내면 그림을 따라다니는 말풍선이 몇 초 떠 있다 사라진다. 빠른 반응은 Firebase 설정(`apps-script/FIREBASE.md`), 없으면 Apps Script 로 1~3초 지연
9. **청소 미션**: 강사가 [🧹 바다 청소] 또는 [🌲 숲 청소]를 누르면 무대에 쓰레기가 흩어지고 수거선(바다)·수거함(숲)이 나타난다. 아이는 조종판 가운데 [줍기]로 가까운 쓰레기를 집고(캐릭터에 달라붙음, 버튼이 [놓기]로 바뀜) 수거 장소 옆에서 [놓기] → +1. 다른 곳에서 놓으면 다시 떠다니거나 바닥으로 떨어진다. **숲 청소는 분리수거**: 수거함이 일반·종이·플라스틱·병·금속 5개이고 종류가 맞아야 +1, 틀리면 "여기 아니야! ○○ 쓰레기야"와 함께 떨어진다(페트병·비닐=플라스틱, 종이컵·종이=종이, 캔=금속, 유리병=병, 포장지·장화=일반). 점수판이 프로젝터 왼쪽 위에 뜨고, 다 치우거나 강사가 [청소 끝]을 누르면 1·2·3등 발표
10. **친구하기·씨름**: 화살표로 친구 그림 가까이 가면 조종 화면에 [친구하기]·[씨름하기]가 뜬다. 씨름은 상대가 수락하면 8초 연타 대결(방향을 바꾸면 2점), 강사 예시 캐릭터는 수락 없이 바로. 예시 캐릭터는 아이 말(안녕·같이 놀자·씨름하자·으악 등)에 답하고 반응한다
11. **마법의 밤 전시**: 그림 만들기에서 [🖼️ 전시 작품]을 고르면 그림·별자리(⭐ 별 도구: 톡톡 찍으면 별이 선으로 이어짐)를 그려 무대로 보낼 수 있다. 마법의 밤에서 내 캐릭터를 작품 옆으로 옮겨 [줍기] → 작품이 따라오고 [↺][↻]로 돌린 뒤 [놓기] → 그 자리에 빛나는 테두리와 "○○의 작품" 이름표로 전시된다(다시 들어 옮길 수 있다)
12. 수업이 끝나면 **수업 끝 · 전체 초기화**("지움" 입력) — 다음 날 수업을 위해 그림·배경을 모두 지운다

## 3. 무대 규칙

그림은 카테고리(물고기·고래·상어·잠수함·바닥생물·새·사람·육지동물·배·탈것·비행기·가벼운 것·무거운 것)로 나뉘고, 공간마다 다르게 움직인다.

| | 제주 바다 | 옛 포구 마을 | 마법의 밤 |
|---|---|---|---|
| 물고기 | 헤엄 | 물속이라 보이지 않고 물결만 | 규칙 없음 |
| 고래·돌고래 | 헤엄 | 가끔 물 위로 뛰어오름 | 〃 |
| 상어 | 헤엄 | 등지느러미만 수면 위 | 〃 |
| 게·조개·소라 | 바닥을 김 | 모래밭 | 〃 |
| 새 | 떠올라 수면에 둥둥 | 하늘을 낢 | 〃 |
| 사람 | 헤엄 | 걷기 / 헤엄 / 배 타기 | 〃 |
| 배 | 수면 | 바다 위 | 〃 |
| 자동차·비행기·무거운 것 | 가라앉아 바닥에 누움 | 땅 위 / 비행기는 하늘 | 〃 |

네 번째 공간 **제주 숲**(오름·나무·흙길)은 땅과 하늘만 있어 물고기류는 땅에서 퍼덕인다. 규칙에 묶인 그림(가라앉은 것, 물 밖으로 못 나가는 것)은 아이가 조종해도 "난 못 움직여…"만 말한다.

**아이가 쓴 설명이 규칙보다 우선한다.** "물속을 날아다니는 자동차"라고 쓰면 자동차가 물속을 자유롭게 다닌다.
(지금은 설명의 낱말로 판정한다. 서버가 붙으면 AI가 그림과 설명을 함께 읽어 같은 형식으로 판정한다.)

**도안을 따라 그리면 부위가 따로 움직인다.** 도안마다 어디가 다리·날개·꼬리인지(영역과 관절) 정해져 있어서, 아이 그림에서 그 부분을 잘라 관절을 중심으로 돌린다.
게는 다리 8개와 집게, 새는 날개 위아래, 사람·해녀는 팔다리(땅에서는 걷고 물에서는 몸을 눕혀 수영, 해녀는 숨 쉬고 잠수했다 올라옴), 참고래는 꼬리·가슴지느러미, 산갈치는 긴 몸이 물결, 조개는 껍데기를 여닫으며 통통, 오징어는 다리와 지느러미, 문어는 다리 8개, 자동차는 바퀴, 잠수함은 프로펠러.
"내 마음대로"·사진은 부위 정보가 없어 전체가 흔들리는 기본 움직임이다.

아이가 만든 배경은 아이가 고른 종류(물속 / 땅과 하늘 / 물·땅·하늘 / 규칙 없는 곳)와 직접 끌어 놓은 물 표면선·땅선으로 규칙이 정해진다.

## 5. 지금 되는 것 / 안 되는 것

**되는 것** — 세 화면 모두, 같은 컴퓨터의 브라우저 창끼리 연결된 상태에서 전 과정.
시험: `teacher/` 를 열고 [프로젝터 창 열기], 같은 브라우저에서 `kid/` 를 연다.

**서버를 붙이면** (`apps-script/SETUP.md`) — 아이 폰 → 프로젝터 전달, AI로 바꾸기·AI 오리기, 서버 보관함(기기가 바뀌어도 유지), 강사 갤러리·삭제·초기화가 모든 기기에 적용, 자리별 현황.
서버는 이전 강의와 같은 방식이다: Apps Script 하나, API 키는 `setApiKey()` 로 스크립트 속성에만 저장, 배포 URL을 `app.json` 의 `exec` 에 넣는다.
`app.json` 의 `exec` 가 비어 있으면 같은 기기 창 간 통신만 쓴다.

---

**파일을 올린 뒤 화면이 안 바뀌면** GitHub Pages 캐시(10분) 때문이다. JS 파일은 페이지가 항상 새로 받도록 해 두었지만, HTML 자체가 바뀐 경우는 10분 뒤 새 탭에서 연다.

**프로젝터 화면은 한 곳에서만 연다.** 두 군데서 열면 서로 위치·대결 정보를 덮어써서 친구하기·씨름이 엉킨다.
