# 스케치 무대 (ai-class_sketrch)

아이들이 그린 그림·색칠한 도안·찍은 사진이 프로젝터 위 무대(제주 바다 · 옛 포구 마을 · 마법의 밤)에 들어가 움직이는 어린이 AI 수업 도구다.
미디어아트 전시장의 "그림이 벽에서 살아 움직이는" 형식을 교실로 가져왔다.

아이는 계정을 만들지 않는다. 자리 번호와 별명만 쓴다.
이전 강의(제주민속자연사박물관 「우리 집 추억! 박물관 추억!」)의 전시물을 도안과 태그로 이어받았다.

---

## 1. 화면 세 개

| 화면 | 주소 | 누가 | 하는 일 |
|---|---|---|---|
| 아이 | `kid/` | 아이 (폰·태블릿) | 자리 번호+별명 → 도안 고르기 → 그리기/사진 → 설명 쓰기(태그 조합) → AI로 바꾸기 또는 그대로 → 무대로 보내기. 배경(장소) 만들기, 내 무대에서 미리 실행 |
| 강사 | `teacher/` | 강사 (노트북) | 허용 스위치 6개, 무대 공간 선택, 장면 버튼(친구·씨름·춤), 예시 넣기, 아이 배경 심사 → 프로젝터에 올리기, 무대 비우기·전체 지우기 |
| 프로젝터 | `stage/` | 프로젝터 | 무대만 표시. 첫 터치로 소리·전체화면 |

첫 화면 `index.html` 에 세 링크가 있다.

---

## 2. 수업 흐름

1. 강사가 프로젝터 화면을 띄우고 한 번 누른다 (소리 켜짐)
2. 강사 화면에서 **그리기 열기** → 아이들이 도안을 골라 그린다
3. 강사가 **AI로 바꾸기** 또는 **그대로 쓰기**를 열면 아이 화면에 완성 버튼이 나타난다
4. 아이가 **무대로 보내기** → 프로젝터에 "7번 번개상어" 꼬리표와 함께 등장
5. 강사가 **씨름 대회 · 춤 시간 · 친구 만들기**로 장면을 연다
6. 수업 후반: 강사가 **배경 만들기**를 열면 아이가 직접 장소를 그리고 물·땅 선을 정한다 → **선생님께 보여주기** → 강사 화면에 카드가 뜨고, 누르면 프로젝터가 그 배경으로 바뀐다 → 다른 아이들도 그 배경에 그림을 넣는다

---

## 3. 무대 규칙

그림은 카테고리(물고기·고래·상어·잠수함·바닥생물·새·사람·육지동물·배·탈것·비행기·가벼운 것·무거운 것)로 나뉘고, 공간마다 다르게 움직인다.

| | 제주 바다 | 옛 포구 마을 | 마법의 밤 |
|---|---|---|---|
| 물고기 | 헤엄 | 물속이라 보이지 않고 물결만 | 규칙 없음 |
| 고래·돌고래 | 헤엄 | 가끔 물 위로 뛰어오름 | 〃 |
| 상어 | 헤엄 | 등지느러미만 수면 위 | 〃 |
| 게·조개·소라 | 바닥을 김 | 모래밭 | 〃 |
| 새 | 떠올라 수면에 둥둥 | 하늘을 낢 | 〃 |
| 사람 | 헤엄 | 걷기 / 헤엄 / 배 타기 | 〃 |
| 배 | 수면 | 바다 위 | 〃 |
| 자동차·비행기·무거운 것 | 가라앉아 바닥에 누움 | 땅 위 / 비행기는 하늘 | 〃 |

**아이가 쓴 설명이 규칙보다 우선한다.** "물속을 날아다니는 자동차"라고 쓰면 자동차가 물속을 자유롭게 다닌다.
(지금은 설명의 낱말로 판정한다. 서버가 붙으면 AI가 그림과 설명을 함께 읽어 같은 형식으로 판정한다.)

아이가 만든 배경은 아이가 고른 종류(물속 / 땅과 하늘 / 물·땅·하늘 / 규칙 없는 곳)와 직접 끌어 놓은 물 표면선·땅선으로 규칙이 정해진다.

## 4. 파일

```
index.html          첫 화면 (세 링크)
kid/                아이 화면
teacher/            강사 화면
stage/              프로젝터 화면 (?dev=1 이면 시험용 조작판)
stage_engine.js     공통 무대 엔진. 프로젝터와 아이의 "내 무대"가 같이 쓴다
stage_guides.js     도안 17종 (윤곽선). stage/guides_test.html 에서 한 번에 본다
stage_demos.js      예시 그림 생성기 (강사 [예시 넣기])
stage_bus.js        강사 ↔ 프로젝터 ↔ 아이 통신
assets/sound/       음원 (상황마다 *_1, *_2 두 개 중 무작위)
app.json            Apps Script 주소 (서버 연결 후 사용)
docs/               구조 문서, Suno 음원 프롬프트
```

---

## 5. 지금 되는 것 / 안 되는 것

**되는 것** — 세 화면 모두, 같은 컴퓨터의 브라우저 창끼리 연결된 상태에서 전 과정.
시험: `teacher/` 를 열고 [프로젝터 창 열기], 같은 브라우저에서 `kid/` 를 연다.

**안 되는 것 (서버 필요)**
- 아이 폰 → 프로젝터: 기기가 다르면 Apps Script 서버가 있어야 전달된다
- AI로 바꾸기, 복잡한 배경에서 대상만 오리기(AI 오리기)
- 보관함 서버 저장(지금은 기기별 localStorage), 강사 [전체 지우기]의 서버 반영
- 자리별 현황·한도

서버는 이전 강의와 같은 방식이다: Apps Script 하나, API 키는 `setApiKey()` 로 스크립트 속성에만 저장, 배포 URL을 `app.json` 의 `exec` 에 넣는다.

---

## 6. 시험용 주소

- `kid/?all=1` — 강사 허용 없이 전부 열린 아이 화면
- `stage/?dev=1` — 프로젝터 화면에 조작판 표시
- `stage/guides_test.html` — 도안 모아 보기

---

## 7. 지키는 것

- 아이의 이름·연락처·학교를 받지 않는다. 자리 번호와 별명만 쓴다
- API 키를 저장소에 넣지 않는다
- 파일명은 영문으로 한다
