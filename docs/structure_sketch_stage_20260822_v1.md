# 스케치 무대 — 전체 구조 v1
**작성일:** 2026.08.22

## 1. 수업 흐름 (2단계)
1단계 정해진 배경 3개(제주 바다·옛 포구 마을·밤의 박물관)에 아이 그림이 들어감
2단계 아이가 직접 배경(장소)을 그리고 설명을 붙여 "내 무대"에서 실행 → 강사가 골라 프로젝터에 올림 → 다른 아이들도 그 무대에 그림을 넣음

## 2. 페이지 3개 + 서버 1개
| 구성 | 기기 | 역할 |
|---|---|---|
| ① 아이 페이지 kid/ | 폰·태블릿 | 입장(번호+별명) · 그림 만들기 · 배경 만들기 · 내 무대 · 보내기 |
| ② 강사 페이지 teacher/ | 노트북 | 허용 스위치 · 공간 선택 · 장면 버튼 · 아이 배경 심사 · 현황 · 비우기/지우기 |
| ③ 프로젝터 페이지 stage/ | 프로젝터 | 무대 표시만. 강사 명령·새 작품을 서버에서 2~3초마다 받음 |
| 서버 Code.gs | Apps Script | 저장(Drive+Sheet) · AI 호출(Gemini, 키는 여기만) · 상태 중계 |
공통 엔진 `stage_engine.js` 하나를 ③과 ①의 "내 무대"가 같이 쓴다.

## 3. 아이 페이지 화면
A 입장: 자리 번호(1~15) + 별명(직접 입력 또는 추천 별명 12개 중 선택)
B 홈(내 보관함): 내가 만든 그림·배경 목록. 강사가 [전체 지우기] 하기 전까지 유지
C 그림 만들기: 전시물 고르기(9종+자유) → 그림판(붓·색·지우개·되돌리기·도안 밑그림) 또는 사진 찍기
   → 설명 쓰기(자유 글 + 추천 태그 클릭 조합) → [AI로 바꾸기] / (허용 시) [그대로 쓰기] → 보관함 저장
D 배경 만들기(강사가 열어야 보임): 가로 화면 그림판 또는 사진 → 장소 설명(자유 글 + 태그)
   → 장소 종류 고르기: 물속 / 땅과 하늘 / 물·땅·하늘 / 규칙 없는 곳(우주·꿈)
   → 물 표면선·땅선을 손가락으로 끌어 맞춤(종류에 따라 0~2개) → 보관함 저장
E 내 무대: 내 배경(또는 기본 3개, 또는 공개된 친구 배경) + 내 그림들을 넣어 실행. 친구·씨름·춤도 됨
F 보내기: 그림 → "지금 프로젝터 무대로" · 배경 → "선생님께 보여주기"(심사 대기)

## 4. 강사 페이지
- 허용 스위치: 그리기 열기 · 사진 올리기 · AI 바꾸기 · 그대로 쓰기 · 배경 만들기 · 친구 배경 보기
- 무대 공간: 기본 3개 + 아이 배경 목록(썸네일·별명·설명) → [프로젝터에 올리기] / [내리기]
- 장면: 친구 만들기 · 씨름 대회 · 춤 시간 · 자동 놀이 · 예시 넣기 · 소리
- 현황: 자리별 별명·보낸 수·한도 추가, 작품 숨기기
- [무대 비우기](아이 보관함 유지) · [전체 지우기]("지움" 입력)

## 5. 규칙 판정 (설명 > 카테고리)
- AI가 그림+설명을 읽어 {cat, abil:{fly,swim,surface,sink,ground,jump}} 반환. 설명이 있으면 abil 우선
- 아이 배경의 물리: 장소 종류 + 아이가 끌어 놓은 선 두 개로 band(surface·swim·bottom·sky) 결정. "규칙 없는 곳"은 밤의 박물관과 같음
- AI로 배경 설명도 읽어 "물이 있음/하늘 있음"을 추천값으로 미리 채워 줌(아이가 고치면 아이 값 우선)

## 6. 데이터 (Sheet)
items: id, 시각, 자리, 별명, 종류(sprite|world), 카테고리, 능력, 설명, 원본ID, AI결과ID, 최종ID, 배경정보(종류·선·규칙), 대상무대, 상태(보관|대기|공개|숨김)
state(스크립트 속성): 허용 스위치 6개, 현재 무대(기본 키 또는 world id), 장면 명령(종류+시각), 소리, 리셋 번호

## 7. 만드는 순서
1 엔진 분리 + 프로젝터 페이지(기본 3개 + 아이 배경 불러오기)
2 강사 페이지(같은 노트북 창 간 통신으로 먼저 동작 → 서버 연결)
3 아이 페이지(A→F)
4 Code.gs 무대 버전(저장·AI·상태·허용·심사)
5 연결 시험(사용자 API 키) · 음원 교체 · 도안 · 강사 안내문
